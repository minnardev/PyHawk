# `math.hwk` — математические функции

Дополнительные функции поверх встроенных операторов `+`, `-`, `*`, `/`, `%`, `^`.

```
hawk

import math

print sqrt(16)           # 4
print pow(2, 10)         # 1024
print round(3.7)         # 4
print abs(-5)            # 5
print factorial(5)       # 120
print gcd(12, 18)        # 6
print pi()               # 3.141592653589793
```

| **Категория** | **Функция** | **Описание** |
| --- | --- | --- |
| **Базовые** | `sqrt(x)` | Корень квадратный |
| | `pow(base, exp)` | Возведение в степень |
| | `abs(x)` | Модуль |
| | `sign(x)` | Знак: `-1`, `0` или `1` |
| | `floor(x)` | Округление вниз |
| | `ceil(x)` | Округление вверх |
| | `round(x)` | Математическое округление |
| | `max(a, b)` | Максимум из двух |
| | `min(a, b)` | Минимум из двух |
| | `clamp(x, lo, hi)` | Ограничивает значение диапазоном |
| **Тригонометрия** | `sin(x)` | Синус (радианы) |
| | `cos(x)` | Косинус |
| | `tan(x)` | Тангенс |
| | `asin(x)` | Арксинус |
| | `acos(x)` | Арккосинус |
| | `atan(x)` | Арктангенс |
| | `atan2(y, x)` | Арктангенс двух аргументов |
| **Константы** | `pi()` | π |
| | `e()` | e |
| | `tau()` | 2π |
| **Логарифмы** | `log(x)` | Натуральный логарифм |
| | `log10(x)` | Десятичный логарифм |
| | `log2(x)` | Двоичный логарифм |
| | `exp(x)` | e^x |
| **Целочисленные** | `factorial(n)` | Факториал |
| | `gcd(a, b)` | Наибольший общий делитель |
| | `lcm(a, b)` | Наименьшее общее кратное |
