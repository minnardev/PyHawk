# `math.hwk` — математические функции

Дополнительные функции поверх встроенных операторов `+`, `-`, `*`, `/`, `%`, `^`.
Большинство математических функций теперь являются built-ins и не требуют
подключения модуля.

```
hawk

import math

print sqrt(16)           # 4
print pow(2, 10)         # 1024
print round(3.7)         # 4
print abs(-5)            # 5
print factorial(5)       # 120
print gcd(12, 18)        # 6
print pi()               # 3.141592653589793
```

| **Категория** | **Функция** | **Описание** |
| --- | --- | --- |
| **Базовые** | `abs(x)` | Модуль |
| | `sign(x)` | Знак: `-1`, `0` или `1` |
| | `max(a, b)` | Максимум из двух |
| | `min(a, b)` | Минимум из двух |
| | `clamp(x, lo, hi)` | Ограничивает значение диапазоном |
| **Тригонометрия** | `sin(x)` | Синус (радианы) — built-in |
| | `cos(x)` | Косинус — built-in |
| | `tan(x)` | Тангенс — built-in |
| | `asin(x)` | Арксинус — built-in |
| | `acos(x)` | Арккосинус — built-in |
| | `atan(x)` | Арктангенс — built-in |
| | `atan2(y, x)` | Арктангенс двух аргументов — built-in |
| **Константы** | `pi()` | π |
| | `e()` | e |
| | `tau()` | 2π |
| **Целочисленные** | `factorial(n)` | Факториал |
| | `gcd(a, b)` | Наибольший общий делитель |
| | `lcm(a, b)` | Наименьшее общее кратное |

> Built-ins: `sqrt`, `pow`, `floor`, `ceil`, `round`, `log`, `log10`, `log2`, `exp` доступны без импорта.
