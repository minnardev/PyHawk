# `sound.hwk` — воспроизведение звука

Кроссплатформенный playback для macOS, Linux и Windows.

```
hawk

import sound

play("alert.wav")

# beep() — встроенная функция, работает без импорта
beep()
```

| **Функция** | **Что делает** |
| --- | --- |
| `play(path)` | Воспроизводит аудиофайл в фоне |
| `beep()` | Системный звуковой сигнал (встроен, не требует импорта) |
| `play_sound(path)` | Синоним `play()` (встроен, не требует импорта) |

**Поддерживаемые форматы:** `.wav`, `.mp3`, `.ogg`, `.flac` — зависит от системных кодеков.
